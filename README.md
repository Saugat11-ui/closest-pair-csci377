# Closest Pair of Points

CSCI 377 Computer Algorithms group project

Team: Nima Sherpa, Saugat Giri, Avinaya Adhikari

Language: Python 3 (no extra libraries needed)

## What it does
Finds the two closest points among n points in the plane.
It compares a divide-and-conquer algorithm, O(n log n), against brute force, O(n^2).

## How to run
- Demo: python closest_pair.py
- Correctness tests: python test_closest_pair.py
- Timing benchmark: python benchmark.py

## Files
- closest_pair.py: both algorithms (divide-and-conquer and brute force)
- test_closest_pair.py: checks divide-and-conquer against brute force
- benchmark.py: first timing results
